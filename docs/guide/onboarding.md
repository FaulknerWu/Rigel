# 开发环境搭建与项目启动指南

本文档旨在指导新加入项目的研发人员快速了解代码库的基本结构，并完成本地运行环境的配置与核心服务的构建。

---

## 1. 核心目录结构

本系统的顶层目录包含三个功能独立的区块，了解它们的定位有助于规范后续的开发工作：

*   **`core/`**：系统的源代码目录，使用 Rust 语言编写，涵盖主程序及模块实现，是日常开发的重心区域。
*   **`docs/`**：项目的综合文档库。包含需求规范（`prd.md`）、架构设计与迭代计划板。
*   **`labs/`**：内部技术预研与实验专区，用于存放未经整合的原型系统及可行性验证代码，请谨慎基于此目录进行生产级别的开发。

## 2. 工具链与运行环境准备

系统强依赖 Rust 编译环境与运行时用于支持实体节点的图数据库平台 FalkorDB。

### 阶段一：安装并配置 Rust 工具链

系统核心程序由 Rust 开发。如需在本地安装，请执行以下官方提供的初始化命令：

```bash
# macOS 或基于 Linux 的系统环境
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```
*提示：请参考 `core/rust-toolchain.toml` 文件中锁定的参数，确保本地工具链的版本与系统一致。*

### 阶段二：部署 FalkorDB 数据库

Rigel 体系下的代码结构语义网（含节点与边）依赖 FalkorDB 进行存储与索引支持。为便于快速隔离部署，推荐依赖 Docker 在后台维护该服务：

```bash
docker run -p 6379:6379 -it --rm falkordb/falkordb:latest
```
请在开发过程中保持此容器服务的主动运行状态。

---

## 3. 本地构建与验证测试

在配置好上述前置条件后，请按如下流程编译并检验本地开发环境。

1. **进入开发级目录工作区**：
```bash
cd core
```

2. **拉取依赖与构建可执行文件**：
首次执行构建过程会涉及 Tree-sitter 等底层组件的获取及编译，可能需要一些时间，请耐心等待完成。
```bash
cargo build
```

3. **执行冒烟测试及单元测试（建议）**：
验证环境完整性及底层逻辑的可运行状态。
```bash
cargo test
```

4. **调起系统核心入口并核实 CLI 状态**：
项目对外接口采用标准命令行接口（CLI）。执行附带帮助参数的构建命令以确保流程接通。
```bash
cargo run -- --help
```
*(在后续迭代中，将逐步丰富该 CLI 工具层的功能子命令，以覆盖索引、抽取、问答等场景)*
