# EXP-001: Java AST 解析可行性实验

## 1. 背景

Rigel 的索引主链路依赖源码解析结果来抽取实体、构建关系，并为后续增量索引与证据输出提供稳定的数据输入。如果 Java AST 解析方案在实体识别、源码定位、错误恢复或增量重解析上存在明显缺口，那么后续的存储模型、索引流程与关系构建都会建立在不稳定前提上。

## 2. 实验目标

本实验需要回答以下问题：

1. 当前选定的 Java AST 解析方案，是否能稳定解析 Rigel 首期所需的 Java 源码样本。
2. 是否能从语法树中稳定抽取文件、类、函数三类基础实体。
3. 是否能拿到实体抽取所需的关键元信息，包括名称、层级归属、源码位置、限定名拼装所需片段。
4. 当源码存在语法错误或不完整片段时，解析是否仍能返回可用的部分结构，而不是整文件报废。
